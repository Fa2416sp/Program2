# Program2

## Описание
**Program2** - это консольное приложение на C#, которое выполняет вычисления на основе введенных пользователем радиуса и высоты.

## Как использовать
1. Склонируйте репозиторий:
    ```bash
    git clone https://github.com/Fa2416sp/Program2/
    ```
2. Перейдите в директорию проекта:
    ```bash
    cd Program2
    ```
3. Соберите проект:
    ```bash
    dotnet build
    ```
4. Запустите приложение:
    ```bash
    dotnet run
    ```

## Пример использования
После запуска программы, вам будет предложено ввести радиус (L) и высоту (d, d1). Программа выполнит вычисления и выведет результаты V1, V2, m1, m2, m, S1, S2, Sk и S.

Пример ввода:
`L = 5 d = 10 d1 = 2`


Пример вывода:
`Результаты: V1 = 392.70 V2 = 153.94 m1 = 3102.33 m2 = 1216.13 m = 1886.20 S1 = 157.08 S2 = 94.25 Sk = 153.94 S = 559.21`
